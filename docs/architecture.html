Order Lifecycle

sequenceDiagram
    actor User
    participant Reception
    participant Parser
    participant KitchenProxy
    participant Kitchen
    participant ThreadPool
    participant Stock

    User->>Reception: margarita S x2 and regina M x1
    Reception->>Parser: parse line
    Parser-->>Reception: 3 pizzas parsed

    loop for each pizza
        Reception->>KitchenProxy: send PizzaPacket
        KitchenProxy->>Kitchen: write to order FIFO
        Kitchen->>ThreadPool: submit cookPizza
        ThreadPool->>Stock: consume ingredients
        Stock-->>ThreadPool: ok
        Note over ThreadPool: sleep bakeTime x multiplier
        ThreadPool->>Kitchen: write result to result FIFO
        Kitchen-->>KitchenProxy: pollResult
        KitchenProxy-->>Reception: PizzaPacket result
        Reception-->>User: Order N is ready
    end

IPC Wire Format

sequenceDiagram
    participant Sender as Sender (KitchenProxy or Kitchen)
    participant FIFO as FIFO (kernel buffer)
    participant Receiver as Receiver

    Sender->>FIFO: write 4 bytes: payload length N
    Sender->>FIFO: write N bytes: serialized PizzaPacket
    Note over Sender,FIFO: Single write syscall, fits in PIPE_BUF, atomic

    FIFO-->>Receiver: read 4 bytes: length N
    FIFO-->>Receiver: read N bytes: payload
    Receiver->>Receiver: memcpy into PizzaPacket struct

Stock Replenishment

graph TD
    A["Stock created: 5 units x 9 ingredients"] --> B["replenishLoop starts"]
    B --> C["sleep restockInterval ms"]
    C --> D["lock mutex"]
    D --> E["set all ingredients to 5"]
    E --> F["unlock mutex"]
    F --> C

    G["cookPizza thread"] --> H["lock mutex"]
    H --> I{"all ingredients available?"}
    I -- yes --> J["deduct each ingredient"]
    J --> K["unlock mutex, return true"]
    I -- no --> L["unlock mutex, return false"]
    L --> M["retry or fail order"]
